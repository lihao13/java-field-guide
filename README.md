# Java Field Guide

一个面向前端开发者的 Java 后端实战学习路线站点，迁移自 [java.evanqhu.me](https://java.evanqhu.me)。

## 本地预览

这是一个 React SPA 的静态构建产物，包含首页、六个 `/learn/:slug` 学习章节和 `/glossary` 术语页。

本地预览：

```bash
python3 -m http.server 4173
```

然后访问 http://localhost:4173。

## 部署

项目已配置为 GitHub Pages 项目站点，地址为：

https://lihao13.github.io/java-field-guide/

学习进度和主题设置保存在浏览器 `localStorage` 中，无需数据库。
